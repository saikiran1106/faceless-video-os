# Wild-doc examples

Filled-in direction files for the opening of a (made-up) savanna survival documentary. Copy them into a project
(`02-direction/` for shotlist/graphics/picks/refs, the project root for `style.json`) after
`faceless wild-doc new ... --script script.example.txt --audio <your narration of it>`.
Stock ids and ref picks must come from your own `stock-search` / `refs-search` contact sheets.
Full guide: [docs/18-wild-doc-style.md](../../../docs/18-wild-doc-style.md).
