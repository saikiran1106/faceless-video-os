the owner reported 7 word defects on the Dyuta Sabha master. I also measured the track
at 22.3% silence and decided to "fix" the pacing at the same time.

**Why it matters:** the pause change touched every unit, so a 7-sentence repair
became a 9-unit regeneration. Then I made pace a hard gate and raised the retake
cap to 3 in the same run, so takes with **zero content defects** were rejected
for tempo. ~12,000 of the ~30,000 characters spent were that error. He never
asked about pacing and never complained about it.

**How to apply:**
- Fix exactly what was reported. Nothing else changes in the same pass.
- If a separate problem is measured, SHOW the measurement and let him decide.
- Never change more than one variable per paid run (already in
  [[elevenlabs-credit-waste-rules]] — this is the same lesson, re-learned).
- Tempo/pace is a PREFERENCE: it ranks takes, it never fails one. Only real
  defects (truncation, insertion, repetition, stutter) may spend a retake.
- Honour the standing halt: check burn rate after unit 1, every run
  ([[credit-spend-announce-first]]).
