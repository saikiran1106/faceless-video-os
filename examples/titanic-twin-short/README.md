# Example: The Titanic Had a Twin (Short, AI voice)

Reference artifacts showing what each stage's JSON looks like when filled in well.

| File | Stage |
|---|---|
| `brief.json` | brief |
| `script.json` | script — hook, one promise, sourced claims, comment CTA |
| `visual_bible.json` | visual bible — style/negative contracts, a character and two locations |
| `beat_manifest.json` | directed beats (timings from the offline demo's audio) |

Copy one into a project's stage folder as a starting point, or point your agent at this folder:
"use examples/titanic-twin-short as the pattern".
